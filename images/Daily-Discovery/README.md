# Daily Discovery image assets

This folder contains self-hosted image assets for the Daily Discovery project. Assets are grouped into one subfolder per Google Sheet tab and use `day-01` through `day-31` filenames.

The `manifest.json` file records the original source URL, download status, replacement strategy, and local path for every entry. Downloaded Wikimedia assets retain their source URL for attribution and review. SVG files marked as local fallback artwork are generated placeholders for rows where no downloadable external image was available.
